# Catwatch (celular)

App Expo/React Native: painel do dia, câmeras ao vivo, editor de zonas, cadastro de gatos
(foto/galeria/câmera), histórico com correção e **aba Câmera**, que transforma o celular
em uma câmera do servidor.

```
npm install
npx expo start          # Expo Go no celular (mesma rede Wi-Fi do servidor)
npx expo run:android    # build nativo
```
Na primeira abertura: endereço do servidor (`192.168.0.10:8000`) e token.
